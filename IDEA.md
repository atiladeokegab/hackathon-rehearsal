# The idea

Zeus writes this once the lead has agreed the idea, and no issue is created before it is
complete. If your task doesn't fit this page, open a change-request (AGENTS.md §7).

## Problem

Hackathon teams lose hours when every agent one-shots its own version of the project.

## The idea

A rehearsal repo that proves the teamwork kit end to end with tiny scripts.

## What we build

- a word-count script
- a greeting script
- a demo script

## What we don't build

- anything with dependencies, a UI, or a server

## The demo, in one line

Each script runs with python3 and prints one line.
